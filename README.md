# موقع محمد لمو — دليل سريع

## الملفات
- `data.js` ← **الملف الوحيد الذي تعدّله**: كل النصوص والروابط والدورات والمتجر والأعمال (بثلاث لغات).
- `index.html` ← هيكل الصفحة و SEO.
- `style.css` ← التصميم. `app.js` ← يبني الصفحة من data.js.
- `favicon.svg` ← الشعار. `robots.txt` و `sitemap.xml` ← لمحركات البحث.

## كيف تضيف شيئاً جديداً؟
1. افتح `data.js`.
2. انسخ عنصراً موجوداً داخل القسم المناسب (`works` أو `courses` أو `shop`) والصقه تحته.
3. عدّل النصوص الثلاثة (ar / fr / en) والرابط `url`.
4. احفظ وارفع الملف. ينعكس التغيير فوراً.

## ما يجب تغييره أولاً
- في `data.js`: رقم واتساب (`contact.whatsapp`) بصيغة دولية، وروابط يوتيوب وتيكتوك وماسنجر.
- في `index.html` و `robots.txt` و `sitemap.xml`: استبدل `YOUR-DOMAIN` برابط موقعك، واستبدل روابط `sameAs`.
- صورتك: ضعها في مجلد `images/` واكتب مسارها في `person.photo`. غلاف كتاب روبيك: ضعه في `images/` واكتب مساره في `img` داخل عنصر الكتاب.

## النشر المجاني (GitHub Pages)
1. أنشئ مستودعاً باسم `اسمك.github.io` وارفع كل الملفات.
2. من Settings ← Pages اختر الفرع `main`.
3. سيصبح الموقع على `https://اسمك.github.io`.

## كيف يجده الناس عند كتابة اسمك؟
1. سجّل الموقع في **Google Search Console** وأرسل `sitemap.xml`.
2. ضع رابط الموقع في وصف قناة يوتيوب وحساب تيكتوك وصفحة فيسبوك.
3. استعمل اسمك بالصيغتين «محمد لمو» و «Mohamed Lemmou» في كل حساباتك.
4. حدّث الموقع باستمرار (دورة جديدة، عمل جديد)، فهذا يرفع ترتيبه.

## تحميل نسخة ويندوز مباشرة (بدون صفحة MediaFire)
1. انسخ ملف `ZED_Soroban_Studio.rar` إلى مجلد جديد اسمه `downloads` داخل الموقع.
2. في `data.js` داخل `zed.apps` عند نسخة ويندوز اكتب: `file: "downloads/ZED_Soroban_Studio.rar"`.
3. بعدها يبدأ التحميل فور الضغط على الزر، ولا يتوقف الرابط أبداً.
